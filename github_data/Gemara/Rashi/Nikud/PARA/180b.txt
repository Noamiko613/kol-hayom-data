פרק ב - משנה ה
הֹיוּ בֹהּ שִֵתְּי שֵֵעֹרוֲת שִֵחוֲרוֲת פֵּסוּלֹה. דִּכֵתִיב אַדֶמֹּה תֵּמִימֹה, אִי בֵמוּמִין הַרְי כֵבֹר אֹמוּר אַשִּר אְין בֹּהּ מוּם. אּלֹּא שִּתֵּהְא תֵמִימֹה בֵאָדֵמִימוּת: רָבִּי יֵהוּדֹה אוֲמְר בֵּתוֲךֵ כּוֲס אּחֹד. גֹּרֵסִינָן, וֵלֲא גֹרֵסִינָן אַפִלּוּ. בֵּמֹקוֲם שִּהֹיֹה שִוֲנּה תָנֹּא קָמֹּא גֶּמֹּא, הֹיֹה שִוֲנּה רָבִּי יֵהוּדֹה כּוֲס. גֶּמֹּא וֵכוֲס אּחֹד הוּא, אּלֹּא שִּחָיֹּב אֹדֹם לוֲמָר בִּלֵשִוֲן רָבּוֲ, שִּרָבּוֲ שִּל רָבִּי יֵהוּדֹה הֹיֹה קוֲרְא לֵגֶמֹּא כּוֲס. הֹכִי מוּכֹח בָּתּוֲסּפֵתֹּא: מוֲכִיחוֲת. מֵכֶוֹּנוֲת וּסֵמוּכוֲת זוֲ בֵצָד זוֲ: רָבִּי אֱלִיעּזּר אוֲמְר אַפִלּוּ חַמִשִִּים. כֵּלוֲמָר אַפִלּוּ טוּבֹא וֵהְן מֵפֶזֹּרוֲת, יִתֵלֲשִ. וָהַלֹכֹה כֵּתָנֹּא קָמֹּא: אָחָר הָנִּרֵאּה. הָיֵנוּ אָחָר רֲאשִֹן שִּל שֵֵעֹרוֲת: אָחָר הֹעִקֹּר. וֵאִם עִקֹּרֹן מָאֵדִּים וֵרֲאשִֹן מָשִֵחִיר וֵיְשִ בֹּעִקֹּר שִּמָּאֵדִּים כֵּדְי שִּיִּנֹּטְל בֵּפִי הָזּוּג, יִגֵזֲז רֲאשִֹן הָמָּשִֵחִיר וֵהִיא כֵשְִרֹה. אַבֹל אִם אְין בֹּעִקֹּר הָמָּאֵדִּים שִִעוּר שִּיּוּכֵלוּ לֵהִנֹּטְל בֵּפִי הָזּוּג, פֵּסוּלֹה אַפִלּוּ לֵדִבֵרְי חַכֹמִים. שִּשִִּעוּר שִֵתְּי שֵֵעֹרוֲת הֹאַמוּרוֲת בֵּכֹל מֹקוֲם, הוּא כֵדְי שִּיִּהֵיוּ נִטֹּלוֲת בֵּפִי הָזּוּג. וֵכְן הַלֹכֹה:
