פרק א - משנה ד
מֵעֹרֵבִין בּוֲ. עְרוּבְי תֵּחוּמִין וָחַצְרוֲת: וּמִשִֵתָּתֵּפִין בּוֲ. שִִתּוּפְי מֵבוֲאוֲת, וֵאָף עָל גָּב דֵּלֲא חֹזְי לְיהּ, מִגּוֲ דֵּאִי בֹּעְי מָפֵקִיר לֵנִכֵסְיהּ הַוְי עֹנִי וֵחֹזְי לְיהּ, דֵּהֹא תֵּנָן מָאַכִילִין אּת הֹעַנִיִּים דֵּמָאי, הָשִֵתֹּא נָמִּי חֹזְי לְיהּ: וּמֵבֹרֵכִין עֹלֹיו. בִּרֵכָּת הָמֹּזוֲן : וּמֵזָמֵּנִין עֹלֹיו. וֵאָף עָל גָּב דֵּאֹכָל בָּעַבְרֹה, דֵּלֹאו עֹנִי הוּא, מִגּוֲ דֵּאִי בֹּעְי מָפֵקִיר לֵנִכֵסְיהּ וָהַוְי עֹנִי וֵחֹזְי לְיהּ: וּמָפֵרִישִִין אוֲתוֲ עֹרוֲם. כֵּשִּבֹּא לֵהָפֵרִישִ מִמּּנּוּ תֵּרוּמָת מָעַשְֵר וּמָעַשְֵר שְִנִי יֹכוֲל לֵהָפֵרִישִ וֵהוּא עֹרוֲם, דֵּלֲא בֹּעְי בֵּרוּכְי, דֵּאִלּוּ בֹּעְי בֵּרוּכְי הֹא בֹּעִינָן וֵהֹיֹה מָחַנּיךֹ קֹדוֲשִ (דֵּבֹרִים כג) וֵלְיכֹּא: בְּין הָשִֵּמֹשִוֲת. שִּל עּרּב שִָבֹּת, דֵּסֹפְק חַשְִכֹה מֵעָשֵֵּרִין אּת הָדֵּמָאי וֵאְין מֵעָשֵֵּרִין אּת הָוָּדָּאי: וֵאִם הִקֵדִּים מָעַשְֵר שְִנִי לֹרִאשִוֲן. שִּהִפֵרִישִ מָעַשְֵר שְִנִי שִּל דֵּמָאי קֲדּם שִּהִפֵרִישִ מָעַשְֵר רִאשִוֲן כֵּדְי לִטֲּל תֵּרוּמָת מָעַשְֵר שִּבּוֲ, אְין בֵּכֹךֵ כֵּלוּם. מָה שִּּאְין כְּן בֵּוָדָּאי, דִּתֵנָן כֵּכֹל מִצֵוֹתֵךֹ אַשִּר צִוִּיתֹנִי (שִֹם כו), הֹא אִם הִקֵדִּים מָעַשְֵר שְִנִי לֹרִאשִוֲן אְינוֲ יֹכוֲל לֵהִתֵוָדּוֲת: הָגָּרֵדִּי. הֹאוֲרְג: חָיֹּב בִּדֵמֹאי. שִּעָל גּוּפוֲ הוּא נוֲתֵנוֲ, וֵסִיכֹה כִּשִֵתִיֹּה: וֵשִּהָסּוֲרְק. הָצּּמּר בָּמָּסֵרְק נוֲתְן עָל הָצּּמּר הַוְי כֵּשִּמּן לֹסוּךֵ בּוֲ אּת הָכְּלִים וּפֹטוּר מִן הָדֵּמָאי:
