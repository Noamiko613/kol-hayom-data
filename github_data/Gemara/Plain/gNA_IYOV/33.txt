איוב פרק-לג

רוח . רצון . כמו הנני נותן בו רוח ( ישעיה לז ) : ונשמת . מל' נשימה ונשיבה והוא ענין מאמר הבא בהפחת הרוח :
קורצתי . נחתך ונחטב צלמי והוא מל' קרץ מצפון ( ירמיה מז ) :
תבעתך . מל' בעתה ורעדה : ואכפי . מל' כפיה ונגישה כמו כי אכף עליו פיהו ( משלי טז ) :
זך . מלשון זכות ובהירות : חף . נגרד ומנוקה ובדרז''ל למסמך לחפיפה טבילה ( נדה סו ) :
תנואות . עלילות ודברים המבוטלים וכן וידעתם את תנואתי ( במדבר יד ) ויתכן שהוא הפוך מן תואנה הוא מבקש ( שופטים יד ) :
בסד . הם כבלי עצים לסגור בהם רגלי התפוס וכן ותשם בסד ( לעיל יג ) :
ירבה . יגדל כמו ורבי המלך ( ירמי' מא ) :
ישורנה . יראנה כמו אשורנו ולא קרוב ( במדבר כד ) :
ובמוסרם . מוסר יסורים : יחתום . ענין גמר והשלמה וכן ועל החתום ( נחמיה י ) ובדרז''ל כל חותמי ברכות ( ברכות סג ) :
וגוה . כמו וגאוה :
בשלח . בחרב כמו ויעש שלח לרוב ( דה''ב לב ) :
והוכח . ענין גמול עונש וכן והוכחתיו בשבט אנשים ( ש''ב ז ) : איתן . חזק כמו איתן מושבך ( במדבר כד ) :
וזהמתו . ענין מיאוס ותיעוב ובדרז''ל ואין מעבירין הזוהמא ( חולין קה ) ור''ל המאוס והלכלוך :
ושפו . ענין כתיתה כמו הוא ישופך ראש ( בראשית ג ) :
פדעהו . כמו פדהו :
רטפש . הוא מלה מורכבת מן רטוב ומן פש שהוא ענין רבוי כמו פשה תפשה ( ויקרא יג ) : עלומיו . נעוריו כמו בן מי זה העלם ( ש''א יז ) :
יעתר . ענין מרבית התפלה כמו ויעתר יצחק ( בראשית כה ) :
ישור . יצעד וילך כמו ואשרו בדרך בינה ( משלי ט ) : העויתי . העקמתי והוא מל' עון ועיות :
ואאלפך . אלמדך כמו יאלף עונך פיך ( לעיל טו ) :
