# הלכות איסורי ביאה

יֵשׁ בִּכְלָלָן שֶׁבַע וּשְׁלֹשִׁים מִצְות. מִצְוָה אַחַת עֲשֵׂה. וּשְׁלֹשִׁים וְשֵׁשׁ מִצְות לֹא תַעֲשֶׂה. וְזֶה הוּא פְּרָטָן:
