# הלכות אישות

יֵשׁ בִּכְלָלָן אַרְבַּע מִצְוֹת. שְׁתֵי מִצְות עֲשֵׂה. וּשְׁתֵי מִצְוֹת לֹא תַעֲשֶׂה. וְזֶה הוּא פְּרָטָן:

לִשָּׂא אִשָּׁה בִּכְתֻבָּה וְקִדּוּשִׁין. שֶׁלֹּא תִּבָּעֵל אִשָּׁה בְּלֹא כְּתֻבָּה וּבְלֹא קִדּוּשִׁין. שֶׁלֹּא יִמְנַע שְׁאֵר כְּסוּת וְעוֹנָה. לִפְרוֹת וְלִרְבּוֹת מִמֶּנָּה:
