# הלכות יסודי התורה

יֵשׁ בִּכְלָלָן עֶשֶׂר מִצְות. שֵׁשׁ מִצְות עֲשֵׂה. וְאַרְבַּע מִצְות לֹא תַעֲשֶׂה. וְזֶהוּ פְּרָטָן: לֵידַע שֶׁיֵּשׁ שָׁם אֱלוֹהַּ. שֶׁלֹּא יַעֲלֶה בַּמַּחֲשָׁבָה שֶׁיֵּשׁ שָׁם אֱלוֹהַּ אַחֵר זוּלָתִי ה'. לְיַחֲדוֹ. לְאָהֳבוֹ. לְיִרְאָה מִמֶּנּוּ. לְקַדֵּשׁ שְׁמוֹ. שֶׁלֹּא לְחַלֵּל שְׁמוֹ. שֶׁלֹּא לְאַבֵּד דְּבָרִים שֶׁנִּקְרָא שְׁמוֹ עֲלֵיהֶם. לִשְׁמֹעַ מִן הַנָּבִיא הַמְדַבֵּר בִּשְׁמוֹ. שֶׁלֹּא לְנַסּוֹתוֹ:

וּבֵאוּר כָל הַמִצְוֹת הָאֵלוּ בִּפְרָקִים אֵלוּ:
