# הלכות שבועות

יֵשׁ בִּכְלָלָן חָמֵשׁ מִצְוֹת. אַחַת מִצְוַת עֲשֵׂה. וְאַרְבַּע מִצְוֹת לֹא תַעֲשֶׂה. וְזֶה הוּא פְּרָטָן:

שֶׁלֹּא לִשָּׁבַע בִּשְׁמוֹ לַשֶּׁקֶר. שֶׁלֹּא לִשָּׂא שְׁמוֹ לַשָּׁוְא. שֶׁלֹּא לִכְפֹּר בְּפִקָּדוֹן. שֶׁלֹּא לִשָּׁבַע עַל כְּפִירַת מָמוֹן. לִשָּׁבַע בִּשְׁמוֹ בֶּאֱמֶת:
