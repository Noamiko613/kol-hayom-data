# הלכות כלאים

יֵשׁ בִּכְלָלָן חָמֵשׁ מִצְוֹת לֹא תַעֲשֶׂה. וְזֶה הוּא פְּרָטָן:

שֶׁלֹּא לִזְרֹעַ זְרָעִים כִּלְאַיִם. שֶׁלֹּא לִזְרֹעַ תְּבוּאָה אוֹ יָרָק בְּכֶרֶם. שֶׁלֹּא לְהַרְבִּיעַ בְּהֵמָה כִּלְאַיִם. שֶׁלֹּא לַעֲשׂוֹת מְלָאכָה בְּכִלְאֵי בְּהֵמָה כְּאֶחָד. שֶׁלֹּא לִלְבּשׁ כִּלְאַיִם:

וּבֵאוּר מִצְוֹת אֵלוּ בִּפְרָקִים אֵלוּ:
