# Kol Hayom Data

This repository contains a rebuilt text library generated from raw Torat Emet sources and Tur assets from the local Siddur project.

## Structure

- `prayers/` preserved from the existing repo
- `tanach/torah/` full-book Torah texts plus parashot and aliyot
- `tanach/neviim/` and `tanach/ketuvim/` clean book-level texts and mefarshim
- `mishna/` by seder and masechet
- `gemara_bavli/` by masechet and daf
- `rambam/` main text and mefarshim
- `tur/` merged Tur texts plus available JSON assets and commentaries
